# Breakdown

## Part 1
The function takes an extra parameter for the chain length, which is different between the example
and the real input.
```q
chain:5
x:enlist"3, 4, 1, 5"
```
By convention, the input is a list of strings, but there is only one line, so we take the first
element, split on commas and trim the results (the trimming is not necessary for the real input
but it is for the example input), then convert the results to integers:
```q
q)trim ","vs first x
,"3"
,"4"
,"1"
,"5"
q)lens:"J"$trim ","vs first x
q)lens
3 4 1 5
```
The calculation of the list is done in an iterated function. The accumulator contains 3 elements:
the current elements of the list, the current position and the skip count. The initial state is:
```q
q)s:(til chain;0;0)
q)s
0 1 2 3 4
0
0
```
An example of calculating a single iteration:
```q
q)len:lens 0
q)len
3
```
We cache the count of the list, then generate the indices using `til` and shifting to the current
position. The indexes must be modulo the list size to wrap around.
```q
q)s[1]+til len
0 1 2
q)idx:(s[1]+til len)mod c:count s 0
q)idx
0 1 2
```
We update the list elements at these indices:
```q
q)s[0;idx]:reverse s[0;idx]
q)s[0]
2 1 0 3 4
```
We update the current position by adding the skip count and the reversed length:
```q
q)s[1]:(s[1]+len+s[2])mod c
q)s[1]
3
```
We update the skip count. This doesn't wrap around.
```q
q)s[2]+:1
q)s[2]
1
```
We return the updated state. The code of the iterated function ends here.

Iterating the function results in the final state:
```q
q)s:{[s;len]idx:(s[1]+til len)mod c:count s 0;s[0;idx]:reverse s[0;idx];s[1]:(s[1]+len+s[2])mod c;s[2]+:1;s}/[(til chain;0;0);lens]
q)s
3 4 2 1 0
4
4
```
The answer is the product of the first two elements of the first element of the state.
```q
q)s[0;0 1]
3 4
q)prd s[0;0 1]
12
```

## Part 2
Example input:
```q
x:enlist"1,2,4"
```
By convention, the input is a list of strings, so we take the first and only element. We cast it to
long and append the constant lengths as specified:
```q
q)`long$first x
49 44 50 44 52
q)lens:(`long$first x),17 31 73 47 23
q)lens
49 44 50 44 52 17 31 73 47 23
```
We perform an iteration similar to the one in part 1. The difference is this time we always do 256
iterations, and the input list is not just `lens` but its repetition 64 times. The latter can be
generated by enlisting it, taking 64 elements from the resulting list (which simply repeats it), and
razing the result.
```q
q)raze 64#enlist lens
49 44 50 44 52 17 31 73 47 23 49 44 50 44 52 17 31 73 47 23 49 44 50 44 52 17 31 73 47 23 49 44 50..
q)sp:first{[s;len]idx:(s[1]+til len)mod c:count s 0;s[0;idx]:reverse s[0;idx];s[1]:(s[1]+len+s[2])mod c;s[2]+:1;s}/[(til 256;0;0);raze 64#enlist lens]
q)sp
43 245 254 123 6 64 65 137 115 127 130 167 8 202 181 232 134 34 88 162 87 25 133 141 248 136 49 63..
```

We perform a cumulative bitwise XOR on the sublists. Since this is not a built-in operation, we have
to implement it using `vs` and `sv` to convert between number and boolean list, and `<>` for boolean
XOR.
```q
q)bitxor:{0b sv <>[0b vs x;0b vs y]}
q)dense:(bitxor/) each 16 cut sp
q)dense
99 150 8 53 188 220 19 15 11 102 215 255 79 106 90 142
```
